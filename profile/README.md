# Paint.NET - Edit a Copy of Your Picture

## Masthead

The image is one you took, scanned, or were allowed to change.
You know the change: a crop, a redaction, a simple mark.
A copy of the file exists before you press save.
The export format is one a normal viewer can open.

## Lede

Paint.NET works in pixels. A crop throws away the edges you did not include. If you might want them, the original file is the only place they remain.
Text you add is part of the picture after you flatten or export a normal image. You will not get the sentence back out as text later.
A blur over a face or a number is only as good as the blur. Look at it at actual size before you send the file.
Zoom in the editor is not the size the file will be. The export size is the size.

## Nut

Open a copy.
Make the one change.
Export to a new name.
Open that name in a viewer and look at the change at actual size.

## Sidebar

Undo is for the session. After you close, the new file is what you saved.
A huge scan can be slow. Save the crop once you have it so a crash does not cost the whole hour.
Color that looks different in a browser may be the screen, not a failed save. Compare in the viewer you will actually use.
Do not edit the file inside a mail attachment and expect the mail to update. Save a file, then attach that file.

## Correction

The save overwrote the original and you hate it. The copy you made first is the way back. If you did not make one, the undo is gone after close.
The export is blurry. You resized too small. Export again from the original at a larger size.
A layer was hidden and the export missed the mark. Turn the layer on and export again.
You wanted to erase a stock watermark you do not have rights to remove. Stop.

## Cut

You do not flatten the only scan of a document before you have a clean copy.
You do not pull images out of a folder you do not own to "practice."
You do not install a plugin pack from a random site on the first day.
You do not leave an unsaved canvas as the only record of a redaction.

## Desk

New name, original kept.
Actual size checked.
The folder is the one you will attach or print from.
After an update, open one copy and export a small test before a pile of scans.

## Not the story

This is not a raw developer for a camera workflow you have not set up. A simpler viewer can still show the JPEG.
It is not a vector tool.
It is not a downloader of images.
A screenshot tool captures the screen. This edits a file that already exists.
Someone else's private photo is not practice material.

## Next edition

The next scan uses the same habit: copy, change, new name, look.
If a size worked for a page, write that width down.
Do not chain plugins until the plain crop is right.
Originals of documents stay until the recipient has the copy they needed.

## Kill

Close after the export is checked.
Delete a bad export so it is not the one you attach.
The original remains.
Uninstall leaves the images. They are ordinary files.

## Copy

What you changed.
New file name.
Whether the original still exists.
The size you exported.

## Close

Editor closed.
No unsaved document.
The folder not full of "final final" names you cannot tell apart. Rename the one you will send.
A shared PC should not keep someone else's photo open.
